# 智慧林草系统操作指南

## 一、系统启动

### 1. 启动后端服务
```bash
# 在项目根目录执行
python app.py
```

### 2. 访问系统
- 打开浏览器，输入地址：http://127.0.0.1:5000
- 系统会自动跳转到登录页面

## 二、登录测试

- 地址：http://127.0.0.1:5000/login
- 界面包含：用户名输入框、密码输入框、登录按钮

### 3. 登录操作步骤
1. 在登录页面输入用户名和密码
2. 点击「登录」按钮
3. 登录成功后，系统会自动跳转到仪表盘页面
4. 登录失败会显示错误提示："用户名或密码错误"

## 五、系统关闭

1. 在运行后端服务的终端中，按下 `Ctrl + C` 组合键
2. 系统会自动关闭数据库连接
3. 终端显示："已断开与SQL Server数据库的连接"

## 六、常见问题排查

### 1. 登录失败
- 检查用户名和密码是否正确
- 检查用户状态是否为「启用」
- 检查后端服务是否正常运行

### 2. 页面无法访问
- 检查URL是否正确
- 检查用户角色是否有访问权限
- 检查后端服务是否正常运行

### 3. API调用失败
- 检查是否已登录（需要有效的session cookie）
- 检查API URL是否正确
- 检查后端服务是否正常运行

## 七、注意事项

1. 系统使用SQL Server数据库，请确保数据库服务正常运行
2. 首次运行需要执行数据库初始化
3. 测试完成后请关闭后端服务
4. 请勿使用生产环境的真实数据进行测试
5. 定期备份数据库数据
