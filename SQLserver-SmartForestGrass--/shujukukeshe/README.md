智慧林草灾害预警系统
一、系统介绍
1. 系统概述
智慧林草灾害预警系统是一个基于 Python 和 SQL Server 开发的综合性管理系统，旨在实现对林草资源的全面监测、灾害预警和科学管理。系统整合了环境监测、灾害预警、资源管理、设备管理和统计分析五大功能模块，为林草资源的保护和管理提供科学依据和技术支持。
2. 核心功能
环境监测：实时监测林草区域的环境数据，包括温度、湿度、风速、降雨量等
灾害预警：根据监测数据和预设规则，自动生成灾害预警信息
资源管理：管理林草资源的分布、数量和变动情况
设备管理：管理监测设备的档案和运行状态
统计分析：生成各类统计报表，支持数据可视化分析
3. 技术栈
开发语言：Python 3.7+
数据库：SQL Server 2016+
数据库驱动：ODBC Driver 17 for SQL Server
架构模式：模块化设计，分层架构
二、第一次使用说明
1. 环境准备
1.1 安装 Python
从官网下载并安装 Python 3.7 或更高版本：https://www.python.org/
安装完成后，在命令行中验证：
bash
运行
python --version
1.2 安装 SQL Server
安装 SQL Server 2016 或更高版本
确保 SQL Server 服务正常运行
启用 SQL Server Browser 服务（可选，用于命名实例连接）
1.3 安装 ODBC 驱动
下载并安装 ODBC Driver 17 for SQL Server：
https://learn.microsoft.com/zh-cn/sql/connect/odbc/download-odbc-driver-for-sql-server
1.4 安装 Python 依赖
bash
运行
pip install pyodbc
2. 数据库初始化
2.1 创建数据库
打开 SQL Server Management Studio (SSMS)
连接到 SQL Server 实例
新建数据库，名称为：SmartForestGrass
2.2 创建表结构
执行 sql_files/ 目录下的 SQL 脚本
执行顺序：
先执行 basic_tables.sql（基础表结构）
再依次执行各业务线脚本：
environmental_monitoring.sql（环境监测）
disaster_warning.sql（灾害预警）
resource_management.sql（资源管理）
equipment_management.sql（设备管理）
statistical_analysis.sql（统计分析）
2.3 插入初始数据
系统会在第一次运行时自动初始化必要的基础数据
或者手动执行相关数据插入脚本
3. 系统配置
3.1 修改数据库连接配置
编辑 main.py 文件，修改数据库连接参数：
python
运行
# 使用Windows认证（推荐）
terminal = DisasterWarningTerminal(db_config={
    'server': '.\\SQLEXPRESS',
    'database': 'SmartForestGrass'
})

# 使用SQL Server认证
terminal = DisasterWarningTerminal(db_config={
    'server': '.\\SQLEXPRESS',
    'database': 'SmartForestGrass',
    'username': 'your_username',
    'password': 'your_password'
})
4. 启动系统
bash
运行
python main.py
5. 登录系统
系统启动后，会提示输入用户名和密码
默认管理员账号：
用户名：admin
密码：123456
登录成功后，进入系统主菜单
三、功能模块使用说明
1. 主菜单
登录成功后，系统显示主菜单：
plaintext
=== 智慧林草灾害预警系统 ===
1. 环境监测
2. 灾害预警
3. 资源管理
4. 设备管理
5. 统计分析
0. 退出系统
2. 环境监测模块（功能 1）
2.1 查看传感器列表
选择子菜单 1
系统显示所有传感器的基本信息，包括传感器 ID、区域 ID、型号和类型
2.2 添加传感器
选择子菜单 2
按照提示输入传感器信息：
区域 ID
设备型号
监测类型（温度、湿度、风速等）
安装时间（格式：YYYY-MM-DD HH:MM:SS）
通信协议
2.3 查看区域监测数据
选择子菜单 3
输入区域 ID、开始时间和结束时间
系统显示该区域在指定时间范围内的监测数据
3. 灾害预警模块（功能 2）
3.1 查看预警规则
选择子菜单 1
系统显示所有预警规则，包括规则 ID、类型、级别和状态
3.2 添加预警规则
选择子菜单 2
按照提示输入预警规则信息：
预警类型（火灾、旱情、病虫害等）
触发条件
预警级别（一般、较重、严重、特别严重）
是否生效（1: 生效，0: 失效）
3.3 查看预警记录
选择子菜单 3
输入区域 ID
系统显示该区域的预警记录，包括预警 ID、时间、内容和状态
4. 资源管理模块（功能 3）
4.1 查看林草资源
选择子菜单 1
系统显示所有林草资源的基本信息，包括资源 ID、区域 ID、类型和面积
4.2 添加林草资源
选择子菜单 2
按照提示输入资源信息：
区域 ID
资源类型
覆盖面积
树种
生长状态
更新人 ID
4.3 查看资源变动记录
选择子菜单 3
输入资源 ID（可选）
系统显示资源变动记录，包括变动 ID、类型、原因和时间
5. 设备管理模块（功能 4）
5.1 查看设备档案
选择子菜单 1
系统显示所有设备的档案信息，包括设备 ID、名称、类型和区域 ID
5.2 查看设备状态
选择子菜单 2
输入设备 ID
系统显示该设备的状态记录，包括状态 ID、时间和运行状态
6. 统计分析模块（功能 5）
6.1 查看报表模板
选择子菜单 1
系统显示所有报表模板，包括模板 ID、名称和类型
6.2 生成报表
选择子菜单 2
按照提示输入报表信息：
模板 ID
区域 ID
开始时间（格式：YYYY-MM-DD HH:MM:SS）
结束时间（格式：YYYY-MM-DD HH:MM:SS）
生成人 ID

五、常见问题
1. 连接数据库失败
检查 SQL Server 服务是否正常运行
检查数据库名称和连接参数是否正确
检查 ODBC Driver 17 for SQL Server 是否已安装
检查 SQL Server 是否允许远程连接
2. 登录失败
检查用户名和密码是否正确
检查用户状态是否为 "启用"
检查数据库中是否存在该用户
3. 功能操作失败
检查输入参数是否符合要求
检查用户权限是否足够
检查相关表结构是否完整
检查网络连接是否稳定
4. 系统运行缓慢
检查数据库索引是否优化
检查服务器性能是否满足需求
检查数据量是否过大，考虑定期清理历史数据
